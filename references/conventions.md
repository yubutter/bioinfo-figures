# 作图约定（视觉语言、尺寸、用户审美、已知的坑）

## 一、跨图类的视觉语言（作图调研二期初筛，2026-10-12）

| 约定 | 写法 | 用在 |
|---|---|---|
| 灰色打底，只给要看的部分上色 | 不显著/背景用 grey85–90，重点用项目颜色表 | 火山图、单成分组成、UMAP 突出子集、相关散点 |
| 黑圈或黑框 = 显著或重点 | 实心点外加黑色细环（0.35–0.45）；格子加黑框（0.4–0.6） | 火山图目标基因、富集网格、热图（开关） |
| 基因名斜体 | `lab_italic("Gapdh")`；点图 x 轴、热图行名、UMAP 小图标题已默认斜体 | 所有出现基因名的地方 |
| 精确 p 值，不打星号；写 n | `fmt_p_math()` / `fmt_p_txt()`；n 是样本数 | 箱线、小提琴、森林图表格、相关散点 |
| 效应量加置信区间 | 森林图、带区间的条或点 | 年龄效应、跨数据集汇总 |
| 柔和配色；浅/深一对；灰白条纹帮助对行 | `DIR_COLS`（#D6604D / #4393C3）；`mix_col()` 造深浅；`stripes = TRUE` | 全部 |
| 小图阵列，坐标统一 | `facet_*` 默认统一坐标；不统一要在图注说明 | 箱线/小提琴、UMAP 小图阵列 |

## 二、用户的审美档案（来自两轮盲选，持续更新）

- 原则 1：不是非黑即白，整合各家优点。
- 原则 2：模板是"缝合体"，越全越好——好手法都留着，用开关控制，默认值取用户选的。
- 原则 3：候选太像时有意加 1–2 个明显不同的（盲选才看得出偏好）。
- 喜欢有颜色层次、但收得住的图：谱系色区分组别 + 同色加深的细边显得精致；面积大的颜色要调淡。
- 线要细：描边、黑圈、边框偏细（网格黑圈从 0.5 调到 0.35）。
- 信息密度高：n、FDR、细胞数直接写在图上（"不要时去掉就行"）。
- 讨厌多余的线：标签引线只在标签离点较远、放不下时出现。
- 版面要饱满但不单调（富集图：点图太空、横条太单调 → 合并）。
- 文字要么放得下，要么进图例（热图组名改右侧图例）。
- 点的大小有上下限：最大的不过大、最小的不过小。
- 一致性：行多时也保留同一种画法（网格 30 行仍选圆点）。
- 同一类数据保留多种画法（箱线版、小提琴版都要）。

## 三、尺寸与字体

- 成图字号 7 pt（标签可到 5.5 pt，下限 5 pt）；字体 Arial；PDF 用 cairo 并保留文字。
- 宽度：`FIG_MM`。高度按内容定：森林图约 22 + 4.2 × 行数 mm；火山图 89 × 80；箱线 4 个分面 120 × 58。
- **移植别人的配方时的换算规则**：字号一律按 7 pt；点的大小按"点 / 面板宽度"的比例换算到成图面板。例：原图 4 英寸（101.6 mm）面板上的点 0.6 → 89 mm 面板上 0.53。
- 线宽：坐标轴、刻度 0.25；描边 0.25–0.35；引线 0.2；阈值虚线 0.25。

## 四、科研护栏（代码里强制，不要关）

- 条件比较的统计单位是样本：模板只显示传入的、按样本模型得到的 p / FDR，不现场检验。
- 箱线/小提琴：n < `min_n_p`（3）不显示 p；n < `min_n_box`（3）不画箱；n < `min_n_violin`（5）不画小提琴。
- 森林图：未检验的行保留，写原因（"too few mice"、"gene too low to test"）。
- 火山图：P < 1e-30 时警告（多半是逐细胞检验）；标签按规则选（每个方向按 P 前 n 个），目标基因要事先定好。
- 富集图：图注写基因集来源和版本、背景基因集、多重校正方法；上调下调分开或用 GSEA。
- UpSet：用 `min_size` 画出所有达到门槛的交集，不用"前 n 个"（会把并列的交集任意切开）。
- 组成图：每个样本一根条，不把一组细胞合在一起画。
- UMAP：只作展示，图注用 `umap_caption()` 写参数并说明距离、簇大小不可解读。

## 五、已知的坑（Windows / 本机环境）

| 坑 | 解决 |
|---|---|
| plotmath 里 `italic(Gapdh)` 把字母排开 | 写成带引号的 `italic("Gapdh")`；用 `lab_italic()` |
| 读 `.qs` 里的 dgCMatrix 后取子集报 "unable to find an inherited method for '['" | 在 `qs::qread()` 之前先 `requireNamespace("Matrix")` |
| fgsea 并行时子进程找不到包 | `Sys.setenv(R_LIBS = paste(.libPaths(), collapse = ";"))`，或 `nproc = 1`（也让结果可复现） |
| `data.table::fread()` 读 .gz 要 R.utils（没装） | 用 `read.csv(gzfile(path))` |
| 含中文的 `.ps1`（如内存看门狗）在 PowerShell 5.1 下语法错误、静默退出 | 存成**带 BOM** 的 UTF-8 |
| ggplot 的 `scale_x_continuous(limits = )` 会删掉被 nudge 推出范围的标签 | 用 `coord_cartesian(xlim = )` |
| patchwork 左右两图行对不齐（表头把 y 范围撑大） | 两边 `coord_cartesian(ylim = 同一范围, expand = FALSE)`，表头画在面板外（`clip = "off"`） |
| 分面图旁边拼一个不分面的图，上下错位 | 给旁边的图也加一个同样样式的分面标题 |
| ComplexUpset 报 "Duplicated aesthetics: fill" 且突出的交集只描了边 | `intersection_size()` 里不要设 `fill`，让 `upset_query()` 填色 |
| ComplexUpset 集合自下而上排列 | 传 `rev(names(sets))` |
| `scale_size_area()` 从 0 起算，最小的点太小 | 用 `scale_size(range = c(下限, 上限))` |
